# HeroVerse

HeroVerse is a modern web application built with React that allows users to explore Marvel characters and their comics. The application features a sleek user interface with animations, responsive design, and seamless integration with the Marvel API.

## Features

- User authentication system
- Search Marvel characters
- View character details and comics
- Responsive design for desktop and mobile
- Modern UI with animations
- Marvel API integration

## Technologies Used

- React
- Vite
- CSS3 with modern features
- Marvel API
- Font Awesome for icons
- Google Fonts (Bangers, Roboto)

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/deepakpathik/Heroverse_project.git
```

2. Install dependencies:
```bash
cd Heroverse_project/comic-library
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and visit `http://localhost:5174`
